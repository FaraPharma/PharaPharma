راه‌اندازی اتصال

برای فعال‌سازی ورود کاربران، اتصال به سرویس Supabase لازم است. مقادیر را از Supabase → Settings → API کپی کنید.

کلید publishable عمومی است؛ امنیت اطلاعات با Row Level Security در سرور تضمین می‌شود. هرگز کلید service_role را وارد نکنید.

برای مشاهده کاتالوگ وارد حساب خود شوید.

ورود فقط با کد شرکت امکان‌پذیر است. کد را از مدیر مجموعه بگیرید.

کاتالوگ محصولات

محصولی پیدا نشد.

بخش دیگری از نام یا کد را امتحان کنید.

راهنمای سریع

  1. جستجو: در نوار بالای صفحه نام کامل یا بخشی از نام، کد یا توضیحات محصول را بنویسید. نتیجه‌ها همزمان با تایپ نمایش داده می‌شوند.
  2. مشاهده محصول: روی هر کارت بزنید تا تصویر بزرگ‌تر و توضیحات کامل نمایش داده شود.
  3. اضافه کردن محصول (مدیر): دکمه «+» پایین صفحه را بزنید، نام، کد و توضیحات را بنویسید و تصویر را انتخاب کنید. تصویر خودکار کوچک و کم‌حجم می‌شود.
  4. ورود گروهی (مدیر): از «تنظیمات ← ابزارهای محصولات» فایل Excel یا CSV محصولات را وارد کنید، سپس تصاویر را یکجا آپلود کنید (نام هر فایل تصویر = کد محصول).
  5. آفلاین: آخرین لیست محصولات روی گوشی ذخیره می‌شود و بدون اینترنت قابل جستجو است؛ تصاویر برای نمایش به اینترنت نیاز دارند.
